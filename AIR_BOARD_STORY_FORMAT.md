# Air board: Story We Love and Care Don't Care item format

Replacement instruction paragraph for the daily air-board generation:

Write every Story We Love and every Care Don't Care item in the new fields, not the old title/read/phone/long fields. Use `headline`: a bold, plain headline that states the key fact. Use `lede`: one line with the key fact and who reported it (for example "according to a new Investopedia study"). Use `bullets`: exactly 2 short bullets with the next most useful facts. Use real numbers only when the story has them; when it does not, give the key facts in plain words at about the same length. Use `source` (publisher name only) and `url` (the exact source page); the board shows these as "Source: Publisher (url)". Use `longHead`: "The Full Story:" and `long`: several paragraphs separated by a blank line that tell the whole story in plain, conversational language, accurate to the source page only. Add a bold-label bullet breakdown at the end of `long` only when the story has natural parts (lines like "- Label - text"); otherwise write flowing paragraphs only. Do not use dashes anywhere except the "Label - text" pattern in those bullets. Do not add facts, numbers, quotes or opinions that are not on the source page, and fetch the source page before writing. Keep `id`, `cat` and a short `title` (used for the 6:10, 7:05 and 8:10 row labels and the Shuffle picker) and a one-line `read`/`phone` prompt if the picker needs them; old items with only title/read/phone/long still render. For Care Don't Care items use the same fields; `line` and `more` are only the fallback. Markdown-ish text is supported in bullets and long: blank line between paragraphs, "- " for bullets, **bold**, and [text](url).

Live test item: Story We Love "ballet" (Ballet Austin TWO, The Seventh Night Sky) in index.html storyPool.

## Source line display
Every item keeps writing `source` (publisher name only, e.g. "Country Now") and `url` (exact article page) as separate fields. The board renders "Source: Country Now" where the publisher name itself is the clickable link (new tab, rel noopener) to `url`, in the first view, the Longer read, Shuffle picker cards and kickers. The raw URL is never shown. Never put a raw URL in visible text (headline, lede, bullets, long, closer). If an item has no `url`, the name shows as plain text. Polls may add an optional `url` and get the same treatment.
